\# 🏦 Console ATM Banking System (C#)



A feature-rich Console Application built with C# that simulates a real-world Automated Teller Machine (ATM) experience with robust input validation and defensive programming principles.



\## ✨ Key Features



\- \*\*🔒 Secure Authentication:\*\* Masked PIN entry (`\*\*\*\*`), account lock mechanism after 3 failed attempts, and PIN modification.

\- \*\*💰 Financial Operations:\*\* Check balance, deposit funds, and withdraw money with a daily limit of 500 JOD.

\- \*\*💸 Money Transfer:\*\* Transfer funds safely between accounts with validation checks.

\- \*\*📜 History \& Reports:\*\* Detailed transaction log with timestamps (`DateTime`) and a comprehensive Mini Statement.

\- \*\*⏰ Operating Hours Check:\*\* Restricts usage to banking hours (06:00 AM - 11:00 PM).

\- \*\*🛡️ Robust Input Handling:\*\* Custom validation logic to ensure the application handles invalid input gracefully without crashing.



\## 🛠️ Built With



\* \*\*Language:\*\* C#

\* \*\*Framework:\*\* .NET Console Application
